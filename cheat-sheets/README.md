# Cheat Sheets

These five pages are for review in the last days before an interview. Each one fits on a screen or two and can be read in under five minutes.

| Page | Use it for |
|---|---|
| [Mobile vs backend system design](mobile-vs-backend-system-design.md) | The differences between the two rounds in one table |
| [iOS vs Android differences](ios-vs-android-differences.md) | A translation table of platform tools and limits |
| [Question bank](question-bank.md) | 40 questions grouped by topic |
| [Common mistakes](common-mistakes.md) | The ten errors that cost the most signal |
| [Four-week plan](four-week-plan.md) | A study schedule of about six hours a week |

The method these pages support is on the [framework page](../framework.md).
